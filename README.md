Emergência — Disque-Rápido de Serviços Emergenciais

Aplicativo Android utilitário que centraliza os principais números de emergência brasileiros em uma única interface, com discagem rápida, informações contextuais por serviço e localização do usuário via GPS usando funções nativas do Android.
